# افغان بیزنس پرو — Afghan Business Pro

پروژه Flutter برای ساخت اپلیکیشن اندروید مدیریت دکان و کسب‌وکار، با رابط فارسی/راست‌چین و پایگاه داده محلی SQLite.

## امکانات پیاده‌سازی‌شده
- داشبورد: فروش، ارزش موجودی، قرض باقی‌مانده، مصارف، اجناس کم‌موجود و سود تخمینی.
- اجناس: ثبت، ویرایش، حذف، دسته‌بندی، قیمت خرید/فروش، موجودی، حداقل موجودی و بارکد متنی.
- فروش: انتخاب جنس، کنترل موجودی، کاهش خودکار موجودی، ثبت نام مشتری، شماره فاکتور و تاریخ.
- قرض‌ها: ثبت قرض و دریافت پرداخت جزئی با کنترل مبلغ.
- مصارف: ثبت عنوان، دسته، مبلغ و یادداشت.
- کارمندان: ثبت نام، تماس، وظیفه، معاش و مقدار پرداخت‌شده.
- مشتریان و تأمین‌کنندگان: ثبت اطلاعات تماس و آدرس.
- گزارش‌ها: خروجی CSV برای بازکردن در Excel و خلاصه مالی.
- پشتیبان‌گیری: اشتراک‌گذاری نسخهٔ پایگاه داده.
- رابط متحرک: بنر گرادیانی با اشکال متحرک و جابه‌جایی نرم صفحات.
- آفلاین: عملیات داده‌ای روی SQLite محلی انجام می‌شود.

## ساخت APK با GitHub Actions
1. این پوشه را در یک مخزن GitHub بارگذاری کن.
2. مخزن را باز کن و به زبانه **Actions** برو.
3. گردش‌کار **Build Afghan Business Pro APK** را انتخاب و **Run workflow** را بزن. با push به شاخهٔ main/master هم اجرا می‌شود.
4. بعد از موفقیت، از همان اجرای workflow بخش **Artifacts** فایل `Afghan-Business-Pro-APK` را دانلود کن.
5. ZIP را استخراج کن و فایل APK را روی گوشی اندروید نصب کن. نصب از منابع ناشناس را فقط برای فایل خودت و در صورت اعتماد فعال کن.

## ساخت محلی
Flutter و Android SDK نصب کن، سپس از ریشهٔ پروژه اجرا کن:
```bash
flutter create --platforms=android --org com.afghanbusiness .
flutter pub get
flutter analyze
flutter build apk --release
```
خروجی معمولاً در `build/app/outputs/flutter-apk/app-release.apk` است.

## نکات مهم و محدودیت‌ها
- این بسته کد منبع و گردش‌کار ساخت APK است، نه فایل APK آماده. در این محیط Flutter/Android SDK برای ساخت و اجرای واقعی در دسترس نبود؛ بنابراین build و نصب نهایی هنوز تأیید نشده است.
- نسخهٔ فعلی مدیریت معاش را به صورت مبلغ معاش/پرداخت‌شده ثبت می‌کند؛ محاسبهٔ مالیات، نوبت‌کاری و سیستم حقوق پیشرفته ندارد.
- اطلاعات چند شعبه فقط در سطح فهرست شعبه طراحی نشده و تفکیک فروش/موجودی هر شعبه هنوز پیاده‌سازی نشده است؛ بنابراین این نسخه را حسابداری رسمی یا چندشعبه‌ای کامل تلقی نکن.
- نسخهٔ پشتیبان فعلاً به اشتراک‌گذاری فایل پایگاه داده انجام می‌شود؛ واردکردن/بازیابی خودکار فایل پشتیبان داخل برنامه هنوز اضافه نشده است.
- بارکد در این نسخه به شکل متن ذخیره می‌شود؛ اسکن دوربین و چاپگر رسید اختصاصی پیاده‌سازی نشده است.
- قبل از استفادهٔ واقعی، با اطلاعات آزمایشی تست کن و نسخهٔ پشتیبان بگیر.
